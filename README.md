# Калькулятор социального благополучия семьи

Одностраничное веб-приложение (без сборки, без Node.js) для расчёта уровня
социального благополучия семьи (лица) по методике, утверждённой приказом
Министра труда и социальной защиты населения РК № 267 от 29.06.2023
(с изменениями № 247 от 17.06.2026).

**Демо:** https://m3etis.is-a.dev/lifelens/

## Возможности

- 8 направлений показателей: доходы, имущество, занятость, соцзащита,
  здравоохранение, образование, жильё, сельское хозяйство
- Итоговый балл `Усб` и категория A–E
- Интерфейс на русском и казахском (переключатель RU/KZ)
- Экспорт результата в декоративную PNG-карточку (1080×1350) с датой и URL
- Суммы дохода в тенге (ориентировочно, ПМ = 46 000 ₸ на 2026 г.)

## Как запустить локально

Откройте `index.html` в любом современном браузере (двойной клик) либо:

```bash
python3 -m http.server 8765
# затем http://127.0.0.1:8765/
```

## Как пользоваться

1. Переключатель **RU / KZ** в шапке меняет язык интерфейса.
2. Ответьте на вопросы по 8 направлениям.
3. Нажмите **«Рассчитать»**.
4. Итог: балл `Усб`, категория A–E и разбивка по направлениям.
5. **«Скачать PNG»** — декоративная карточка с результатом.

## Формула

`Усб = Пдк + Пи + Пз + Псо + Пзд + По + Пж + Псх`

## Категории

| Буква | Название | Диапазон |
|-------|----------------------|----------------|
| A | Благополучный | ≥ 1800 |
| B | Удовлетворительный | 730 … 1799 |
| C | Неудовлетворительный | −30 … 729 |
| D | Кризисный | −458 … −31 |
| E | Экстренный | ≤ −459 |

## Прожиточный минимум

Суммы в опциях дохода рассчитаны от `PM_VALUE` в `app.js`
(46 000 ₸, ориентировочно на 2026 г.). При изменении ПМ поправьте одну
константу — диапазоны в тенге пересчитаются автоматически.
